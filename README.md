# 无限贴纸

个人记录应用，按时间自动沿宽幅 S 形曲线排列便签。前端参考 `wide_s_curve_timeline.html`，交互按《需求文档.md》v0.2 实现。

## 本机体验

需要 Python 3.11 或更新版本。应用没有第三方运行依赖，也不使用外部字体、图片或 CDN。

在本目录运行：

```powershell
python server.py --demo --data-dir .demo-data --port 8788
```

Windows 也可双击 [启动演示.cmd](启动演示.cmd)。打开 http://127.0.0.1:8788 ，演示密码为 `canvas-demo`。演示数据保存在 `.demo-data/`，包含可编辑的示例便签；只允许在本机运行。演示内容与正式数据目录分开。

正式使用时，先设置自己的密码，再启动：

```powershell
python server.py --init
python server.py
```

打开 http://127.0.0.1:8787 。`--init` 也可重置密码，重置会使已有登录会话失效，记录不受影响。

Windows 可双击 [启动个人空间.cmd](启动个人空间.cmd)，首次运行会要求设置自己的密码。启动脚本优先使用本机可用的 Codex Python 运行时，其他电脑使用 PATH 中的 Python 3.11+。

## 已实现的操作

- 进入主题显示全貌。滚轮围绕鼠标缩放，左键拖动空白处或按住中键移动画布。
- 点击小便签在节点附近展开，点击“编辑”修改。单击空白处立即保存：灰钉贴纸卷回小便签，红钉贴纸退出编辑并保持展开。
- 拖动、缩放不结束编辑。长文贴纸内部滚轮滚动正文。
- 贴纸上方钉子在灰色和红色之间切换。已钉住便签保持展开；拖动顶部移动贴纸，拖动右下角调整尺寸。位置、尺寸、钉住状态存入服务器，刷新后保留。
- 新增便签先选择日期与时分，正文为空也保留。编辑时修改时间，结束编辑后重新排序并跟随新位置；同一分钟按创建顺序排列。
- 正文支持段落、粗体、高亮、标题、列表、链接、代码块和多图。代码块阅读时提供复制按钮。
- 图片支持粘贴截图、拖入文件、工具栏上传。点击编辑中的图片可选中，再点“移除图”；阅读时点击图片进入全屏查看，可缩放、拖动和切换图片。
- 创建、重命名主题并更换主题颜色。删除记录进入回收站，可以恢复；不提供主题删除或永久删除。
- 手机支持主题浏览、单指拖动、双指缩放和全屏阅读，不提供编辑。
- ZIP 导出包含所有主题、正文、原始图片、回收站和贴纸布局。导入整体恢复，先校验格式、关联和图片校验值，再自动备份现有数据后替换；登录密码不导入。

## 保存与恢复

输入约 550 毫秒后自动保存；单击空白处立即保存。保存失败时保留编辑内容和展开状态，可以点顶部状态重试；网络恢复后自动重试。图片失败会显示重试和取消按钮，未完成上传时不会当作完整保存并收起。

当前未承诺断网后关闭或刷新页面能够恢复草稿。仍有内容未保存时，离开页面会触发浏览器提示。

默认持久化目录为 `data/`，其中 `canvas.sqlite3` 保存记录、图片、登录密码散列与会话。图片不依赖临时目录或外部地址。删除正文图片后保留原图片数据，以保证其他记录和备份中的引用不失效。

恢复前自动生成的 ZIP 保存在 `data/backups/before-restore-*.zip`（自定义数据目录时对应该目录的 `backups/`）。需要撤销一次恢复，可通过“恢复备份”导入这份 ZIP。

## Linux 服务器运行

将整个项目目录上传到服务器，安装 Python 3.11+。以下示例端口与路径均可替换：

```bash
cd /opt/infinite-stickers
python3 server.py --init --data-dir /var/lib/infinite-stickers
python3 server.py --host 0.0.0.0 --port 8787 --data-dir /var/lib/infinite-stickers
```

运行账号需对数据目录有读写权限。先通过服务器地址访问验证。公网正式使用建议由 HTTPS 反向代理转发到 `127.0.0.1:8787`，并在启动时加入 `--secure-cookie`；该参数只适用于 HTTPS，普通 HTTP 本机预览不要使用。

可用 systemd 保持服务运行，示例见 [deploy/infinite-stickers.service](deploy/infinite-stickers.service)。修改其中的运行账号、工作目录和数据目录后安装到系统服务目录；这些服务器设置尚未在你的 Linux 服务器上执行或验证。

启动后无需构建前端。SQLite 使用事务和 WAL，服务重启后记录与图片仍保留。在线备份使用应用“导出备份”；若直接复制数据库文件，请先停止服务，再复制整个数据目录，避免遗漏 WAL 中未合并的内容。

## 当前实现选择与限制

- 技术方案：原生 HTML/CSS/JavaScript＋Python 标准库 HTTP 服务＋SQLite；单用户密码登录，Cookie 为 HttpOnly，写入带会话校验，正文在服务器端清理。
- 标题可选，未填时取正文摘要，完全空白显示“空白便签”；标签作为可选文本信息，不提供标签筛选。
- 单张图片最大 12 MB，支持 PNG/JPEG/GIF/WebP；首版整体内容容量为 96 MB（包含图片与备份清单预留空间），达到上限时停止新增并提示先导出备份、使用新的数据目录。导出与导入遵循一致的容量检查，避免生成无法恢复的备份；ZIP 导入文件最大 128 MB，展开内容最大 256 MB。这是本实现的保护上限，并非已确认的数据规模目标。
- 便签可调整到宽 320–1000、高 280–1000 个画布像素。右下角提供尺寸手柄。
- 首版采用整体恢复，恢复前二次确认；暂不提供合并导入、Word/PDF 导出。
- 当前自动排序和画布渲染面向个人记录规模，大量记录的性能目标尚未量化；未声称通过大规模压力测试。
- 尚未连接你的 Linux 服务器或配置域名。

## 验证

后端与画布逻辑检查不需要安装依赖：

```bash
python3 -m unittest discover -s tests -v
node --test tests/core.test.js
node --check web/app.js
```

可选浏览器检查使用 Playwright，在本机演示服务运行于 8788 时运行 `node tests/browser.mjs`。它在独立浏览器会话中操作演示数据，并在结束时用原始备份恢复。需要已安装 Playwright 和浏览器；可用 `PLAYWRIGHT_MODULE_PATH`、`BROWSER_EXECUTABLE`、`TEST_BASE_URL` 指定环境。请只对演示数据运行这项检查。

浏览器检查覆盖卷回、拖动不收起、钉住、调整尺寸、刷新保留、改时间、保存失败与重试、图片、代码、回收站、主题隔离、备份导出及手机阅读。

Windows 的自动测试还会在含中文与空格的临时目录中运行两个真实启动脚本，验证服务可访问且中文提示正常。批处理文件采用 ASCII 命令内容及 CRLF 换行，中文提示通过 Python 输出；`.gitattributes` 固定换行格式，避免 Windows 在编码切换时将命令错误截断。
